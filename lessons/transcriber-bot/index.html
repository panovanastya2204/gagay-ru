Бесплатный Telegram-бот, который превращает голосовые и видео в текст

Голосовые, созвоны, вебинары и ссылки на YouTube превращаются в текст с таймингами и спикерами. Обслуживание стоит 0 ₽ в месяц.

#боты#вайбкодинг#автоматизация

Запись созвона, голосовое на десять минут, часовой вебинар. Слушать всё это долго, а в тексте нужное место находится за секунды. Платить за готовый сервис транскрибации мне не хотелось, поэтому я сделала своего бота в Telegram.

Код я не писала. Его написал Claude Code по моему описанию, а я ставила задачи и проверяла результат. В этом уроке показываю весь путь: что получится, какие сервисы нужны, какое ТЗ дать ИИ и как выложить бота в облако, чтобы он работал даже при выключенном компьютере.

Что получится

Вы отправляете боту голосовое, аудио, видео, кружок или ссылку на YouTube или Instagram Reels. Он присылает в ответ файл .txt с расшифровкой.

  • Текст не пересказывается и не сокращается. Бот расставляет пунктуацию, делит на абзацы и исправляет явные ошибки распознавания: имена, компании, термины.
  • В расшифровке есть тайминги, а у одного из движков ещё и спикеры.
  • Речь не переводится. Если внутри русской фразы прозвучала английская, она останется английской.
  • Бот отвечает только вам. Сообщения от других людей он игнорирует.
  • После обработки файлы удаляются, история не хранится.
  • Можно отправить несколько файлов подряд: они встанут в очередь.

Так выглядит результат:

[00:00:00] Спикер 1: Так, ну давайте сегодня обсудим запуск продукта. Я думаю, нам сначала нужно посмотреть, что у нас вообще с воронкой.

[00:00:12] Спикер 2: Да, давайте. Потому что там есть проблема с регистрацией.

За счёт чего это бесплатно

Бот сам ничего не распознаёт. Он отправляет запись в один из трёх «движков», и у каждого есть бесплатный лимит.

ДвижокЧто умеетЦена за час записи
Gemini (Google)Спикеры, тайминги, смешанная речьОколо 4 ₽, в бесплатном лимите 0 ₽
Groq (Whisper)Очень быстро: час записи меньше чем за минуту. Тайминги, без спикеровОколо 4 ₽, в бесплатном лимите 0 ₽
Whisper на своём MacРаботает без интернета, запись никуда не уходит. Тайминги, без спикеров0 ₽, но час записи идёт около 10 минут

Под расшифровкой бот показывает кнопки с доступными движками, и вы выбираете, чем расшифровать. Если движок один, кнопок нет: бот сразу начинает работу.

Сервер тоже бесплатный. Я использую бесплатный тариф Render. Для личного бота его хватает.

Важно про приватность. На бесплатном тарифе Google может использовать присланные записи для улучшения своих моделей. Для конфиденциальных записей выбирайте Whisper на своём компьютере или подключите оплату в Google AI Studio.

Что понадобится

  • Telegram.
  • Аккаунт Google, чтобы получить ключ Gemini.
  • Аккаунт Groq.
  • Аккаунт GitHub, там будет храниться код.
  • Аккаунт Render, там бот будет работать.
  • Claude Code или другой ИИ-помощник, который умеет писать код и запускать его на вашем компьютере.

Программировать не нужно. Нужно уметь внятно описать задачу и аккуратно скопировать несколько ключей.

Шаг 1. Создайте бота в BotFather

  1. Откройте в Telegram @BotFather. У официального бота синяя галочка.
  2. Отправьте команду /newbot.
  3. Введите название, например «Моя транскрибация».
  4. Введите username. Он должен заканчиваться на bot, например my_transcriber_2026_bot.
  5. BotFather пришлёт токен вида 1234567890:AAH.... Сохраните его.

Токен никому не показывайте: с ним можно управлять вашим ботом. Если токен утёк, отправьте BotFather команду /revoke, и он выдаст новый.

Шаг 2. Получите ключи Gemini и Groq

Достаточно одного ключа из двух, но лучше сделать оба: у движков разные сильные стороны.

Gemini. Откройте aistudio.google.com/apikey, войдите через Google, нажмите Create API key и скопируйте ключ. Он начинается с AIza. Карта не нужна. Gemini доступен не во всех странах: если страница не открывается, включите VPN.

Groq. Откройте console.groq.com/keys, войдите через Google или почту, нажмите Create API Key и скопируйте ключ. Он начинается с gsk_. Карта тоже не нужна.

Шаг 3. Узнайте свой Telegram ID

Бот должен отвечать только вам, иначе любой, кто найдёт его в поиске, будет тратить ваш лимит.

  1. Откройте в Telegram @userinfobot и нажмите Start.
  2. Он пришлёт ваш Id, например 123456789.

Это число понадобится на следующем шаге.

Шаг 4. Дайте ИИ техническое задание

Откройте Claude Code, создайте пустую папку под проект и вставьте ТЗ. Ниже текст, который можно взять за основу. В нём описано ровно то, как устроен мой бот.

Сделай личного Telegram-бота для транскрибации на Python (aiogram 3).

Что он делает:
- Принимает голосовые, аудио, видео, видеокружки, файлы документом, ссылки на YouTube и Instagram Reels.
- Извлекает звук через ffmpeg, ссылки скачивает через yt-dlp.
- Расшифровывает и присылает .txt-файл ответом на исходное сообщение.
- Пока идёт работа, показывает «Обрабатываю…», потом удаляет это сообщение.

Движки распознавания (кнопки под сообщением):
- Gemini через google-genai: спикеры и тайминги.
- Groq, модель whisper-large-v3-turbo: быстро, тайминги, без спикеров.
Кнопка движка появляется, только если в настройках есть его ключ.
Если движок один, кнопок нет, бот сразу начинает.

Требования к тексту:
- Не пересказывать и не сокращать. Только пунктуация, абзацы и исправление явных ошибок распознавания.
- Не переводить. Иностранные фразы оставлять на языке оригинала.
- Формат строки: [00:00:00] Спикер 1: текст.
- Длинные записи резать на части примерно по 10 минут по паузам и склеивать с правильными таймингами.

Безопасность:
- Отвечать только пользователю с ALLOWED_USER_ID, остальных игнорировать.
- Все ключи только в .env. Файл .env добавить в .gitignore.
- После обработки удалять все временные файлы.

Запуск:
- Локально на моём компьютере для проверки.
- В облаке на бесплатном тарифе Render: Dockerfile, render.yaml, режим webhook, адрес /health для проверки.

при типичных ошибках. Добавь тесты на основную логику.

Claude Code задаст уточняющие вопросы, напишет код и скажет, куда вставить ключи. Обычно это файл .env в папке проекта:

TELEGRAM_BOT_TOKEN=1234567890:AAH...
ALLOWED_USER_ID=123456789
GEMINI_API_KEY=AIza...
GROQ_API_KEY=gsk_...

Ключи вписывайте в файл сами. Не вставляйте их в чат с ИИ и не отправляйте файл .env никому.

Шаг 5. Проверьте бота на своём компьютере

Попросите Claude Code запустить бота локально и проверьте по порядку:

  1. Откройте своего бота в Telegram и нажмите Start. Он должен поздороваться.
  2. Наговорите короткое голосовое. Появится «Обрабатываю…», через несколько секунд придёт .txt.
  3. Отправьте mp3-файл и ссылку на YouTube. В обоих случаях должен прийти .txt.
  4. Попросите знакомого написать боту. Ему бот отвечать не должен.

Если что-то не работает, скопируйте ошибку из логов и отдайте её Claude Code. Самые частые причины простые:

Шаг 6. Выложите бота в облако

Пока бот запущен на вашем компьютере, он работает только при включённом компьютере. Чтобы он отвечал всегда, его нужно перенести на сервер.

  1. Попросите Claude Code создать закрытый репозиторий на GitHub и отправить туда код. Проверьте, что файла .env в репозитории нет.
  2. Зайдите на render.com и войдите через GitHub.
  3. Нажмите New → Blueprint и выберите свой репозиторий. Render прочитает файл render.yaml и сам поймёт, что запускать.
  4. Render попросит ввести значения ключей. Вставьте те же, что в .env.
  5. Дождитесь окончания сборки и напишите боту.

Дальше всё обновляется само: после каждого изменения кода в GitHub сервер пересобирается.

Бесплатный сервер засыпает после 15 минут без сообщений. Первый ответ после сна приходит примерно через минуту, дальше бот отвечает сразу.

Как устроено у меня: облако и Mac вместе

Я пошла на шаг дальше и соединила облако с домашним компьютером.

  • Облако всегда принимает сообщения и расшифровывает через Gemini и Groq.
  • Когда Mac включён, он сам подключается к облаку. Тогда появляется третья кнопка, и расшифровку делает Whisper прямо на компьютере: бесплатно, без лимитов и без отправки записи в сторонние сервисы.
  • Если Mac выключен, бот продолжает работать через облако.

Этот шаг необязательный. Он нужен, если записей много или они конфиденциальные. Для него подойдёт Mac с чипом Apple (M1 и новее).

Ограничения, о которых стоит знать

  • Размер файла. Через стандартный интерфейс Telegram бот может скачать файл не больше 20 МБ. Это примерно 20 минут голосового или 30–60 минут mp3. Длинное видео проще загрузить на YouTube с доступом по ссылке и отправить боту ссылку.
  • Спикеры. Gemini определяет их по голосу. При похожих голосах и перебиваниях возможны ошибки, тайминги приблизительные.
  • Whisper иногда «придумывает» фразы на тишине. Известные случаи бот отфильтровывает.
  • YouTube с облака. Когда компьютер выключен, ссылки на YouTube расшифровывает только Gemini, и только для открытых видео.
  • Качество записи. Шум, музыка и далёкий микрофон ухудшают результат у любого движка.
